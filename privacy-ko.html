CleanGotchi 개인정보 처리방침

수정일: 2026-11-20

1. 처리 원칙

CleanGotchi는 Mac 안에서 파일 정리와 펫 기록을 처리합니다. 현재 앱에는 개발자 서버로 파일, 펫 기록, 메모리 정보나 사용 통계를 보내는 기능, 광고 추적 도구, 클라우드 동기화, 앱 자체 회원가입이 없습니다. 펫과의 AI 대화도 지원되는 Mac 안에서 앱에 포함된 모델로 처리합니다.

구매 후 사용 소감 이메일을 신청하시면 8절에 적힌 정보만 Google을 통해 개발자 Jay에게 전달됩니다. 건너뛰어도 구매한 기능을 그대로 쓸 수 있어요. 개인정보·지원 링크를 열거나 Apple 구매 기능을 사용하면 해당 외부 서비스의 정책도 적용됩니다.

정리 검사는 항목 이름·경로·파일 종류·크기·수정/상태 변경 시각·파일 식별 정보와 폴더 구성을 확인합니다. 정리 대상을 고르기 위해 사용자 파일의 본문을 읽거나 외부에 업로드하지 않습니다. 휴지통이나 승인한 폴더에 개인 문서가 들어 있으면 그 항목의 이름과 경로도 확인 대상이 될 수 있습니다. 사진 보관함·메일·연락처 등 별도 개인 자료 폴더를 광범위하게 검색하는 기능은 없습니다.

‘열면 바로 살펴보기’는 앱 준비 및 화면 복귀 때 읽기 전용 검사를 할 수 있습니다. ‘내가 누를 때만’은 사용자가 요청하기 전의 캐시·로그 자동 목록 검사를 막습니다. 이 선택과 별개로 앱 실행 중 위 범위의 접근 가능한 휴지통에서 삭제 변화를 관찰합니다. 한 번 검사한 화면의 새로고침, 접근 상태 확인, 사용자가 별도로 켠 휴지통 자동 비우기는 이 선택과 구분됩니다. 검사는 그 자체로 파일을 지우지 않습니다.

캐시·로그 권한은 앱 설정에서 기억한 허락을 취소할 수 있습니다. 휴지통의 전체 디스크 접근 등 시스템 권한은 macOS 시스템 설정에서 관리하며, 앱의 ‘다시 확인’은 시스템 권한을 자동으로 켜거나 끄지 않습니다. 권한을 거절해도 펫과 메모리 상태 등 접근 권한이 필요 없는 기능은 사용할 수 있습니다.

3. Mac 안에 저장하는 정보

  • 펫 종류·이름·성장량·태어난 날·졸업한 날과 선택한 펫
  • 보낸 대화 메시지, 검사를 통과한 펫 답변과 각 메시지의 시각·펫 구분 정보: 이 Mac에서 최근 7일 동안 보관합니다. 답변이 없거나 생성이 취소된 질문도 남을 수 있습니다.
  • 앱이 펫 그림으로 만든 졸업 이미지: 전체 화면을 촬영하지 않으며 화면 기록 권한을 요구하지 않습니다.
  • 정리 이력: 처리 항목 이름, 종류, 용량, 처리 방식과 시각
  • 외부 휴지통 삭제 확인과 중복 먹이 방지에 필요한 로컬 파일 식별값, 확인된 항목의 이름·경로·크기 및 처리 기록
  • 정리 복구 기록: 중단되거나 저장이 덜 끝난 작업을 구분하기 위한 작업 ID, 펫 ID, 처리 결과 및 원본/이동 경로. 문제 복구를 위해 실패한 경로가 남을 수 있습니다.
  • 언어, 표시·크기·위치·움직임, 살펴보기 방식, 휴지통 보관 기간과 자동 비우기 선택
  • 승인한 캐시·로그 폴더를 다음 실행에 다시 열기 위한 macOS 북마크
  • Apple이 제공하는 상품과 가격, 검증된 구매·철회 정보를 이용한 구매 상태. 앱 자체 구매 상태는 실행 중 메모리에 보관합니다. 구매 후 소감 참여를 한 번만 물어보기 위해 구매 시도 또는 확인 시각을 Mac에 잠시 기록합니다. 참여 안내를 표시할 때 이 기록을 지우며, 오래된 기록은 다음 구매 상태 확인 때 정리합니다. 여기에 이메일 주소를 저장하지 않습니다.

기록은 앱 전용 저장소와 웹뷰의 로컬 저장소에 보관됩니다. 대화 기록에는 아래 6절의 최근 7일 보관 기준을 적용합니다. 그 밖에 기록 복구를 위해 필요한 정보가 유지될 수 있으며 해당 기록에는 현재 자동 보관 기간이 정해져 있지 않습니다. 개발 시험용 버전에는 최근 폴더 접근 결과의 오류 코드·시각을 담은 로컬 진단이 추가될 수 있습니다. 이 진단에는 파일 본문이나 북마크 내용이 들어가지 않습니다.

4. 파일을 옮기거나 지우는 방식

  • 캐시·로그: 사용자가 정리를 누르면 검사 기준을 통과한 오래된 항목을 휴지통으로 옮깁니다. 휴지통으로 옮기는 것만으로 같은 양의 디스크 공간이 즉시 확보되는 것은 아닙니다. 휴지통을 비우기 전에는 Finder에서 이동한 항목을 확인해 필요한 곳으로 다시 옮길 수 있지만, 앱이 원래 위치로 자동 복원하는 기능은 제공하지 않습니다.
  • 직접 휴지통 비우기: 확인창에서 사용자가 승인하면 검사 가능한 Mac 내부 휴지통 항목을 보관 기간과 관계없이 영구 삭제합니다. 되돌릴 수 없으므로 내용을 먼저 확인해야 합니다. 끝까지 검사하지 못하거나 처리할 수 없는 항목은 남을 수 있습니다.
  • 휴지통 자동 비우기: 기본값은 꺼짐입니다. 유료 기능을 사용할 수 있는 사용자가 별도로 켠 경우에만 작동합니다. Mac 내부 휴지통에서 10·30·100일 중 선택한 기간과 앱의 검사 기준을 충족한 항목을 앱 실행 중 주기적으로 영구 삭제합니다. 설정을 켜거나 기간을 바꾼 직후 곧바로 삭제하지 않도록 대기 기간을 적용합니다. 정확히 특정 시각에 실행되는 예약 서비스는 아닙니다.

앱이 실행 중이고 휴지통 접근이 허용되면, Finder 등 앱 밖에서 위 범위의 휴지통에 있는 일반 파일을 실제로 삭제한 것이 확인될 때 해당 용량을 현재 펫의 먹이에 반영합니다. 이 관찰 기능은 파일 본문을 읽거나 파일을 옮기거나 지우지 않습니다. 복원·이동 및 디스크 분리를 삭제로 계산하지 않으며, 앱이 이미 먹이로 계산한 파일의 중복 반영을 방지하기 위해 파일 식별값을 로컬에 보관합니다. 관찰 준비 전에 삭제되었거나 앱이 꺼져 있던 동안의 항목은 나중에 추측해 더하지 않습니다. 접근 제한이나 동시에 관찰할 수 있는 파일·폴더 수의 한도 때문에 일부 항목만 확인될 수 있습니다. 심볼릭 링크와 처음 관찰할 때 여러 하드 링크가 있는 파일도 제외합니다. 디스크를 다시 연결하면 새로 관찰을 준비하며, 연결되지 않았던 동안의 삭제량은 소급 반영하지 않습니다. 먹이 양은 확인된 파일의 표시 크기를 기준으로 하며 실제로 늘어난 디스크 여유 공간과 같다는 뜻은 아닙니다.

기록 저장이 실패하면 파일 처리가 이미 끝난 결과와 기록 대기 상태를 구분합니다. 기록 재시도는 이미 처리한 파일을 다시 정리하는 동작이 아닙니다. 처리 여부를 확인할 수 없는 상태에서는 추가 정리가 차단될 수 있습니다.

5. 메모리와 실행 중 앱 정보

메모리 카드가 표시되는 동안 macOS의 sysctl, vm_stat을 이용해 전체 메모리와 사용량을 확인합니다. 표시 가능한 경우 ps의 메모리 크기와 실행 파일 이름/경로를 읽고, 같은 앱의 프로세스를 묶어 메모리를 많이 쓰는 앱을 보여줍니다. 명령줄 인수나 프로세스의 메모리 내용을 읽는 기능은 없습니다.

사용량은 약 3초, 앱 목록은 약 30초 간격으로 갱신될 수 있습니다. 값은 화면과 짧은 메모리 캐시에 사용하며 앱의 영구 기록이나 개발자 서버에 저장하지 않습니다. 앱을 강제 종료하거나 메모리를 강제로 비우지 않습니다. macOS가 앱 목록 조회를 제한하면 전체 사용량만 보일 수 있습니다.

6. Mac 안에서 처리하는 펫 대화

바탕화면 펫을 누르거나 대시보드의 대화 버튼을 누르면 작은 펫 대화창이 열립니다. 메시지를 보내면 앱에 포함된 Gemma 4 E2B 텍스트 모델이 대화 답변을 만듭니다. 앱은 답변에서 확인할 수 있는 펫 이름·성장·먹이·관련 수치와 파일 작업 주장을 현재 기록 및 기능 범위와 대조합니다. 문제가 발견되면 최대 2번 다시 생성해 한 요청에서 총 3개까지 후보를 확인합니다. 이 검사를 통과한 후보만 표시하며, 모두 통과하지 못하면 입력을 남겨 다시 물어볼 수 있게 안내합니다. 이 검사는 제한된 앱 정보에 대한 검사이며, 모든 표현이나 일반 지식의 정확성을 보장하지 않습니다. Finder나 Dock에서 휴지통을 비울 때 먹이와 무료 정리 용량이 어떻게 바뀌는지 물으면, 모델이 해당 언어로 미리 확인한 안내 중 질문에 맞는 답을 고릅니다.

창을 여는 것만으로 답변을 만들지 않습니다. 이 기능은 Apple Silicon과 macOS 14 이상에서 지원하며, 지원하지 않는 Mac에서도 기존 펫과 정리 기능은 사용할 수 있습니다. 모델은 앱에 포함되어 있어 대화할 때 외부 AI 서비스에 접속하거나 모델을 따로 내려받지 않습니다. Python이나 별도 AI 앱을 설치할 필요도 없습니다.

답변 생성에는 직접 입력한 메시지, 선택한 언어, 현재 펫 종류와 저장 이름, 성장 단계, 먹이로 누적된 정리 용량, 다음 목표와 남은 양이 사용됩니다. 이 펫 정보는 앱이 생성할 때마다 저장된 프로필에서 다시 읽으며, 답변을 보내기 전에도 이름·펫과 누적 먹이가 바뀌지 않았는지 확인합니다. 대화 속 주장을 저장된 정보로 취급하지 않습니다. 실제 식사나 먹은 시각을 추적하는 정보는 아닙니다. 메시지는 최대 800자이며 첫 후보를 만들 때 최근 6개 메시지에서 각각 최대 400자를 참고합니다. 짧은 후속 질문에는 앱이 확인한 직전 펫 기록 주제를 참고할 수 있습니다.

같은 요청에서 다시 생성할 때는 앞선 대화 이력을 제외하고 현재 질문·현재 펫 정보와 문제가 발견된 항목의 종류를 사용합니다. 거절된 후보의 문장 자체를 다음 생성에 붙이지 않습니다. 거절된 후보 답변과 검사·재시도용 임시 정보는 처리 중 메모리에서만 사용하며 대화 파일이나 서버에 저장하지 않습니다. 검사를 통과한 답변은 아래의 로컬 대화 기록에 저장합니다.

펫 이름은 대시보드에서 정하며 대화로 바꾸지 않습니다. 현재 정리 후보의 용량·항목수, 파일 이름·전체 경로·파일 본문을 대화에 자동으로 붙이지 않으며, 대화창을 열거나 메시지를 보내는 것이 새 파일 검사를 실행하지 않습니다. 사용자가 직접 입력한 내용은 그대로 대화에 사용되므로 불필요한 비밀 정보는 입력하지 마세요.

보낸 메시지와 검사를 통과한 답변은 이 Mac의 앱 전용 저장소에 저장합니다. 대화창을 닫았다 다시 열거나 앱을 재시작해도 같은 펫의 최근 7일 기록을 이어 볼 수 있습니다. 같은 펫의 이름이나 언어를 바꾸어도 기록은 유지하며, 새로 키우는 다른 펫의 기록과는 섞지 않습니다. 각 메시지가 작성된 시각을 기준으로 7일이 지난 기록을 앱 시작 시, 기록을 읽거나 쓸 때와 앱 실행 중 주기적으로 정리합니다. 앱이 꺼져 있으면 그동안의 삭제는 실행되지 않으며 다음 실행 때 오래된 기록을 정리합니다.
