폴더 접근이 안 될 때

휴지통은 숨김 폴더를 선택하는 방식이 아닙니다. ‘다시 확인’으로 실제 접근 상태를 확인합니다. macOS가 막고 있다면 시스템 설정의 개인정보 보호 및 보안에서 현재 실행하는 CleanGotchi의 전체 디스크 접근 상태를 확인하고 앱을 완전히 종료한 뒤 다시 열어 보세요. 권한을 원하지 않으면 해당 정리 기능을 사용하지 않아도 됩니다. 접근 허용은 정리를 자동 실행하는 동작이 아닙니다.

자동 비우기와 직접 비우기는 다른가요?

자동 비우기는 기본 OFF이며 별도로 켜야 합니다. 선택한 10·30·100일과 대기 기간을 적용하며 앱 실행 중 확인합니다. 직접 비우기는 확인창에서 승인하면 기간과 관계없이 검사 가능한 항목을 영구 삭제합니다. 앱의 휴지통 용량 표시와 직접·자동 비우기는 Mac 내부 휴지통만 대상으로 합니다. 외장 SSD·USB의 휴지통은 Finder에서 확인하고 비워 주세요.

Finder에서 휴지통을 비워도 먹이가 되나요?

CleanGotchi가 실행 중이고 해당 휴지통에 접근할 수 있으면, Finder나 Dock에서 직접 비운 일반 파일도 실제 삭제를 확인한 만큼 먹이로 반영합니다. Mac 내부 휴지통(~/.Trash)과 연결된 쓰기 가능한 로컬 디스크의 본인 휴지통(/Volumes/<디스크>/.Trashes/<현재 사용자 UID>)을 확인합니다. 외장 SSD·USB도 이 범위에 포함하며 다른 사용자의 휴지통은 살펴보지 않습니다. 이는 자동 비우기를 켜거나 새 접근 권한을 자동으로 허용하는 기능이 아니며, 앱이 대신 파일을 지우지 않습니다. 기존 정리 배치나 저장된 파일 식별값으로 이미 먹이로 계산했음을 확인한 항목은 다시 더하지 않습니다.

휴지통 카드에서 확인 준비·일부만 확인 가능·권한 필요 상태를 볼 수 있습니다. 준비 전에 너무 빨리 삭제된 파일, 앱이 꺼져 있던 동안의 파일, 동시에 관찰할 수 있는 파일·폴더 수의 한도나 접근 제한으로 확인하지 못한 항목은 빠질 수 있습니다. 복원하거나 다른 곳으로 옮긴 항목과 바로가기 같은 연결 파일, 처음부터 여러 하드 링크가 있던 파일, 네트워크·읽기 전용 볼륨의 휴지통은 이 기능의 먹이로 계산하지 않습니다. 디스크를 분리해도 먹이로 계산하지 않으며, 다시 연결하면 관찰을 새로 준비합니다. 연결되지 않았던 동안의 삭제나 이미 지운 파일은 나중에 소급 반영하지 않습니다. 먹이 양은 파일에 표시된 크기이며 실제 디스크 여유 공간이 늘어난 양과 다를 수 있습니다. 수동 살펴보기 설정은 캐시·로그 목록 확인 방식이며 이 휴지통 관찰과 별개입니다. 이 기능이 추가되기 전에 구버전 정리 배치의 이름을 바꿨다면, 과거 먹이 반영 여부를 새 이름만으로 복원하지 못할 수 있습니다.
